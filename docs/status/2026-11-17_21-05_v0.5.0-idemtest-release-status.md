## The mid-release discovery: the split was already done

The 20:51 session ended with the kit as a same-module package. A later session (commits 21:22–21:27) split `idemtest/` into its own nested Go module (go.mod requiring root `v0.4.0`), documented in AGENTS.md, with a matching Dependabot entry. The split was NOT reverted (deliberate, mirrored go-sse's `ssetest` — verified against go-sse's actual ssetest/go.mod). Instead, this release completed the split's missing pieces, all of which were release blockers:

1. **CI had zero kit coverage** — `./...` from the root cannot reach a nested module. The test/vet/lint/tidy/govulncheck jobs now run their command inside `idemtest/` with `working-directory` (ci.yml).
2. **The release gate had zero kit coverage** — `pre-release-check.sh`'s vet/build/test/lint/tidy/modverify gates now run in both modules; the godirective gate anchors the floor in both go.mod files; the tidy-copy check covers the nested module.
3. **No ADR existed for the split** — ADR-008 written (decision, release mechanics, internal-rule analysis); dated addenda in ADR-005 and ADR-007; index updated.
4. **Nobody had ever run the kit as a standalone module** — first standalone build/vet/lint/test -race run happened in this session (green, resolving root v0.4.0 from the proxy).
