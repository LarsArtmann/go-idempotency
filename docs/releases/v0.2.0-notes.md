# go-idempotency v0.2.0

**Release date:** 2026-08-29 · **Compare:** v0.1.2...v0.2.0

v0.2.0 completes the interface-first SDK: the `Store` interface plus a reusable
contract test suite that proves any backend implements it correctly, fuzz tests
for panic-safety, and a mechanically enforced deprecation of the in-process
`MemoryStore`.

## Highlights

### Contract test suite for custom backends

`github.com/larsartmann/go-idempotency/contract` ships `RunTests`, a test suite
covering every behavioral invariant of a `Store`: atomicity, TTL expiry,
duplicate detection, concurrency safety (200-goroutine races), and error
semantics. Implement the three-method `Store` interface against your backend
(Redis `SET NX`, SQL `INSERT ... ON CONFLICT DO NOTHING`, ...) and verify it in
one line:

```go
func TestContract(t *testing.T) {
    t.Parallel()
    contract.RunTests(t, func(t *testing.T) idempotency.Store {
        store := mybackend.NewStore(redisClient)
        t.Cleanup(func() { store.Close() })
        return store
    })
}
```

### `MemoryStore` is deprecated — and the deprecation is enforced

`MemoryStore` is for development and testing only: it does not survive
restarts and cannot be shared across instances. Any usage outside `_test.go`
now fails `golangci-lint` (`forbidigo` gate in this repo's config). Removal is
targeted for v1.0. Production code should implement `Store` against a real
backend and validate it with `contract.RunTests`.

### Interface-first by design (ADR-001)

This module deliberately ships no production backend. Drivers, connection
pools, and operational tradeoffs belong to consumers. See
[docs/adr/001-no-backends.md](../adr/001-no-backends.md).

## Behavior changes to review before upgrading

- **Non-positive TTLs are rejected.** `Record` and `CheckAndRecord` return
  `ErrInvalidTTL` (a `Rejection`, non-retryable) for `ttl <= 0`. Previously a
  zero/negative TTL silently recorded an already-past expiry, breaking the
  exactly-once guarantee.
- **`ErrDuplicate` is a `Conflict`** (`go-error-family`): maps to HTTP 409
  downstream, non-retryable. Check with `errors.Is(err, idempotency.ErrDuplicate)`.
- **`Record` never extends a TTL.** Recording an already-recorded,
  non-expired key is a no-op. Expired keys are re-recorded with a fresh TTL.

## Also in this release

- Fuzz tests (`FuzzCheckAndRecord`, `FuzzRecord`) proving panic-safety and
  invariant preservation on arbitrary inputs.
- Memory benchmarks reporting bytes/key and post-sweep reclamation.
- Godoc examples (`ExampleStore`, `ExampleMemoryStore`) and a full Redis
  adapter example in the package docs.
- Race test proving `Close` during concurrent operations is safe.
- CI: coverage reporting, all GitHub Actions pinned by commit SHA.

## Upgrade

```bash
go get github.com/larsartmann/go-idempotency@v0.2.0
```

No new runtime dependencies: `go-error-family` remains the only one.
